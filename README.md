# Cue

Локальные инструменты для Twitch-стрима: опросы, конкурсы, рулетка решений и OBS-виджет.

## Приложение для Windows

Основной вариант распространения — обычный установщик **Cue**. Он включает Node.js и Chromium, открывает панель в отдельном окне и сам запускает локальный сервер для OBS. Стримеру не нужно устанавливать Node.js или запускать командный файл.

Данные приложения находятся в `%APPDATA%\Stream Polls\app-data`. Обновление и переустановка не удаляют шаблоны, опросы и вход Twitch. Вторая копия приложения не запускается; вместо неё открывается уже работающее окно.

Для локальной тестовой сборки Windows-установщика используйте Windows. Основная сборка выполняется GitHub Actions:

```sh
npm install
npm install --prefix ui/panel
npm run pack:win
```

Готовый установщик появится в `release/`. Сборка без настроенного адреса обновлений полностью работает, но раздел обновлений сообщает, что источник пока не задан.

## Stream Dock AJAZZ

Раздел **Stream Dock** объединяет две готовые интеграции для AJAZZ:

- **Cue Control** встроен в приложение и добавляет четыре действия: запуск или завершение опроса одной кнопкой, показ или скрытие OBS-виджета, продление на 30 секунд и применение выбранного шаблона;
- **Twitch для AJAZZ** доступен отдельным готовым установщиком и добавляет 16 действий Twitch, включая чат, клипы, рекламу, смену названия и категории.

1. Установите и один раз запустите **Stream Dock AJAZZ**.
2. В Cue откройте **Stream Dock** и установите `Cue Control`.
3. При необходимости скачайте с этой же страницы `Ajazz-Twitch-Setup.exe` и подтвердите вход на официальной странице Twitch.
4. Назначьте нужные действия на клавиши в редакторе AJAZZ.
5. Оставляйте Cue запущенной во время стрима. Окно можно закрыть в трей, если в настройках включена фоновая работа.

Cue автоматически определяет установленные плагины. Управление опросами работает локально через `127.0.0.1:4317` и не открывается в сеть. Готовый Twitch-плагин публикуется в [репозитории ajazz-plugin-manager](https://github.com/exyyyl/ajazz-plugin-manager/releases/latest).

Локальные сборки не нужны для публикации. Удалить `release/`, `dist/` и временные файлы упаковщика можно одной командой:

```sh
npm run clean
```

## Обновления

В установленном Cue откройте **«Настройки → Обновления → Версии приложения»**. Стабильная и бета-версия хранятся рядом: один раз нажмите «Скачать» для нужной ветки, затем «Перезапустить». Повторное переключение использует локальную копию, работает без сети и не запускает установщик. Кнопка «Проверить» ищет новые выпуски обеих веток; новая сборка скачивается только по явному действию. Обычное закрытие после скачивания не активирует её.

При следующем запуске обычный ярлык открывает последнюю выбранную версию. Новая версия подтверждает успешный запуск после загрузки панели и состояния сервера; если подтверждения не было, следующий запуск возвращается к предыдущей копии. Бета использует отдельную папку `app-data-beta`, которая при первом запуске получает копию стабильных данных. Учётная запись Twitch общая, а изменения настроек и истории в бете не записываются в стабильные данные.

Для новых клиентов релиз должен содержать ZIP с полным приложением и описание `stable-win32-x64.json` либо `beta-win32-x64.json` (для macOS — `*-darwin-arm64.json` или `*-darwin-x64.json`). Сборщик генерирует размер и SHA-512 архива, а внутри приложения — `cue-runtime.json` с версией и платформой. Клиент проверяет описание, контрольную сумму, пути архива и состав сборки до регистрации версии. Для уже установленных старых клиентов Windows-установщик, `.blockmap` и YAML обновлений по-прежнему публикуются: им понадобится одно обновление до выпуска с менеджером версий.

Перед релизом измените версию одновременно в `package.json` и `package-lock.json`, закоммитьте изменения и отправьте тег с той же версией:

```sh
git tag v0.8.3-beta.1
git push origin main v0.8.3-beta.1
```

Workflow `.github/workflows/release-windows.yml` проверит совпадение тега и версии, установит зависимости, запустит typecheck, lint и тесты, соберёт установщик и ZIP, запишет описание ветки и создаст публичный релиз. Артефакты хранятся 14 дней. При ошибке релиз не публикуется. macOS упаковывается командой `npm run pack:mac`: она создаёт DMG, ZIP и описание текущей архитектуры; эти файлы нужно загрузить в тот же GitHub Release.

Стабильный канал использует обычные версии и релизы: `0.8.2` / `v0.8.2`. Бета-канал использует prerelease-версию и опубликованный GitHub pre-release: `0.8.3-beta.1` / `v0.8.3-beta.1`. Draft-релизы менеджер пропускает. Старые релизы без ZIP и описания ветки не поддерживают быстрое переключение. В разработке и браузере кнопки скачивания и запуска отключены.

## Запуск исходной версии

Нужен Node.js 22 или новее. Для разработки установите зависимости и запустите Electron вместе с Vite:

```sh
npm install
npm install --prefix ui/panel
npm run desktop
```

Панель разработки открывается в Electron; Vite использует `http://127.0.0.1:5173`.

- Опросы: http://127.0.0.1:4317/overlay
- Чат: http://127.0.0.1:4317/chat-overlay

Для запуска только локального сервера сначала выполните `npm run build:panel`, затем `npm start`. Все файлы и OBS должны находиться на одном компьютере.

## OBS

1. Запустите приложение.
2. Добавьте источник **Браузер**.
3. Вставьте `http://127.0.0.1:4317/overlay`, размер **480 × 640**.
4. Разместите источник в сцене. Если используете длинные названия и шесть вариантов, увеличьте высоту до 900.
5. Создайте опрос в панели, включите виджет и нажмите «Запустить опрос».

В черновике отдельный оверлей пустой. После запуска он показывает вопрос, ключевые слова, проценты и таймер. После завершения результат остаётся видимым до скрытия или перехода к редактированию. При ничьей выделяются все лидирующие варианты, при нуле голосов победитель не назначается.

## Опрос без оверлея

Выберите **«Только в панели» до запуска**: источник OBS останется пустым с первого момента опроса. Панель станет компактной, покажет вопрос, счётчики, проценты и таймер. Можно совсем не запускать OBS. Сервер приложения должен продолжать работать.

«Включён / Скрыт» переключается в любой момент, включая завершённый опрос, без сброса голосов и времени. Само завершение скрытого опроса не включает оверлей. Предпросмотр остаётся доступен в панели. Результаты в панели видны стримеру даже при включённой настройке «Скрывать результаты до финала».

Во время активного опроса можно изменить правила и добавить новый вариант. Существующие голоса сохраняются; для нового варианта автоматически включается переголосование и остаётся не меньше 30 секунд на повторный выбор. В ленте совпавших сообщений показывается время события Twitch с точностью до секунды.

Режим, выбранный в черновике, сохраняется для следующего опроса. Переключение во время голосования влияет только на текущий опрос; его видимость также переживает перезапуск сервера.

## Шаблоны

Раздел «Шаблоны» открывает локальную библиотеку и полноценный редактор вопроса, вариантов, ключевых слов, длительности, источника голосов и видимости OBS. Текущий опрос можно перенести туда кнопкой «Сохранить как шаблон». Незавершённая форма сохраняет состояние при переходе между разделами.

Шаблоны можно редактировать, закреплять, перетаскивать внутри своей группы и удалять с подтверждением. До 30 шаблонов хранятся в `data/state.json` и доступны после перезапуска.

## Оверлей чата

В разделе «Виджеты» выберите «Чат» в меню слева сверху. Кнопка «Подключить OBS» копирует ссылку `http://127.0.0.1:4317/chat-overlay` для источника «Браузер». Начальный размер — 480 × 720 px; фон источника прозрачный, ширину и высоту можно менять в OBS.

Редактор устроен так же, как у опросов: холст и нижняя панель «Оформление», «Текст», «Цвета», «Сообщения», «Анимация». Открывается только выбранная группа настроек. В «Оформлении» доступны варианты «Студия», «Лента», «Диалог» и «Светлый». Смена оформления сохраняет видимость, таймер и приоритет смайликов. Настройки текста, смайликов, цветов, значков, времени показа и анимации сохраняются и сразу применяются к открытому источнику. Ноль в длительности показа оставляет последние сообщения на экране постоянно. Кнопки «Демо / Твой чат» переключают источник на холсте. Панель «Тест» позволяет одним нажатием выбирать длинные сообщения, текст без пробелов, ссылки и смайлики, а также фон холста. Тестовые сообщения не отправляются в Twitch. После перезапуска Cue источник переподключается автоматически.

Чат и оверлей используют одинаковые смайлики Twitch, 7TV, BetterTTV и FrankerFaceZ. Точный ID из сообщения Twitch имеет приоритет; у сторонних сервисов набор канала важнее глобального. При одинаковых кодах в разных сервисах выберите приоритет в настройках «Сообщения». Версия в расширении браузера может отличаться из-за его настроек или кеша каталога.

## Виджет

Раздел «Виджет» объединяет предпросмотр, управление видимостью оверлея и параметры Browser Source для OBS. Здесь можно скопировать адрес, открыть виджет отдельно и проверить итоговый вид до стрима.

Оформление настраивается локально: доступны акцентный цвет, сплошной или полупрозрачный фон, обычная или компактная плотность, а также отдельное отображение таймера и ключевых слов. Изменения сразу применяются к предпросмотру и открытому источнику OBS и сохраняются после перезапуска.

## Оверлей конкурса для OBS

В «Виджетах → Конкурсы» доступны тот же холст, переключатель «Демо / Текущий конкурс», плавающий «Тест» и подписанные кнопки показа и подключения OBS. Вставьте адрес `http://127.0.0.1:4317/contest-overlay` в источник «Браузер»; рекомендуемый размер указан в «Подключить OBS». Фон источника прозрачный.

Оверлей показывает условия участия (слово, активность или диапазон чисел), таймер, число участников, а затем анимацию выбора и победителя. При повторном выборе он обновляет результат. Победитель определяется сервером; анимация не влияет на случайный выбор. Для конкурса по числу ответ скрыт до завершения. После перезапуска приложение и источник переподключаются автоматически.

Внизу настраиваются размеры, цвета, непрозрачность и видимые элементы. Демо позволяет проверить все состояния без запуска реального конкурса. Оформление сохраняется и входит в резервную копию настроек.

## Конкурсы

В разделе «Конкурсы» можно провести розыгрыш среди активных зрителей, собрать участников по ключевому слову или предложить чату угадать число в заданном диапазоне. Для первых двух режимов победитель выбирается после завершения набора; в числовом режиме побеждает первый зритель с точным ответом. Участие можно ограничить группами зрителей Twitch. Демо-режим позволяет проверить конкурс без эфира.

Победитель выбирается на сервере криптографически стойким генератором случайных чисел. После розыгрыша панель показывает новые сообщения выбранного пользователя, чтобы проверить его присутствие и продолжить общение в чате. Состояние хранится локально в `contest.json` и восстанавливается после перезапуска приложения.

## Рулетка

Раздел «Рулетка» выбирает случайный вариант из списка, отвечает «да/нет» или выбирает число из диапазона. Состояние вариантов и история выборов хранятся локально.

## Подключение Twitch

Cue использует одно Twitch-приложение типа **Public**, зарегистрированное разработчиком. Его публичный Client ID уже включён в сборку; Client Secret не создаётся и в приложение не входит. Стримеру не нужно регистрировать собственное приложение или вводить идентификатор.

1. Нажмите профиль внизу сайдбара и в блоке Twitch выберите **«Подключить»**.
2. Нажмите «Подтвердить в Twitch» и подтвердите код под **аккаунтом стримера**. При необходимости введите показанный код на странице Twitch.
3. Дождитесь имени и аватара аккаунта внизу сайдбара и статуса «Чат подключён».
4. В новом опросе задайте вопрос и ключевые слова, выберите отображение и запустите.
5. Отправьте ключевые слова с нескольких аккаунтов в чат этого канала. Опрос считает сообщения независимо от открытой панели и видимости OBS.

Приложение запрашивает только `user:read:chat` и ничего не пишет в чат. Читает канал вошедшего пользователя через [EventSub WebSocket](https://dev.twitch.tv/docs/chat/authenticating/). Аккаунт и источник голосов фиксируются на время опроса. Демо-кнопки не влияют на опрос Twitch; сообщения Twitch не влияют на демо-опрос. Сообщения из других каналов Shared Chat исключаются.

[Device Code Flow](https://dev.twitch.tv/docs/authentication/getting-tokens-oauth/#device-code-grant-flow) позволяет входить и обновлять токены без Client Secret. Публичный Client ID только обозначает Cue перед Twitch и не даёт доступа к аккаунту. Приложение проверяет токен при запуске и не реже раза в час, обновляет его при истечении и сохраняет заменённый refresh token. После длительного неиспользования или отзыва доступа потребуется повторный вход.

При обычном обрыве связи приложение переподключается автоматически. В панели появляется предупреждение; таймер опроса продолжает идти. **Twitch не повторяет сообщения, потерянные во время такого обрыва**, поэтому часть голосов может не поступить. При плановом переносе WebSocket-сессии старая связь сохраняется до готовности новой. См. [правила восстановления Twitch](https://dev.twitch.tv/docs/eventsub/handling-websocket-events/).

«Отключить аккаунт» останавливает чтение и удаляет локальные токены. Полностью отозвать разрешение приложения можно в настройках подключений аккаунта Twitch.

Источник можно обновлять и отключать при смене сцены: после подключения он получает полное актуальное состояние. Панель и оверлей автоматически переподключаются после перезапуска сервера. Таймер вычисляется от сохранённого времени окончания; если приложение было закрыто до истечения времени, при запуске опрос завершится с сохранёнными голосами.

## Данные и ограничения

- `data/state.json` содержит последний корректный черновик, текущий/завершённый опрос и учтённые голоса. Запись атомарная: сначала временный файл, затем замена основного.
- `data/twitch.json` хранит вход Twitch локально. В установленном приложении соответствующие данные находятся в `%APPDATA%\Stream Polls\app-data`. Токены не передаются в панель/оверлей и не включаются в обновления.
- В разделе «Настройки» можно экспортировать и импортировать черновик, библиотеку шаблонов и оформление виджета. Текущий опрос, голоса и токены Twitch в файл экспорта не входят.
- Тема интерфейса выбирается в настройках: Лайм, Пичи или Лёд. Выбор сохраняется локально и применяется при следующем запуске.
- Корректные изменения черновика сохраняются через 550 мс. Незавершённые поля и дублирующиеся ключевые слова не сохраняются; панель показывает это и предупреждает при закрытии вкладки.
- Сервер слушает только `127.0.0.1`, не публикуется в интернет и не требует хостинга.
- Голос засчитывается при точном совпадении целого сообщения с ключевым словом после Unicode-нормализации, удаления пробелов по краям и приведения к нижнему регистру.
- По умолчанию один голос на зрителя. При включённом переголосовании новый выбор переносит прежний голос. Повторные события не увеличивают счётчики.
- Демо-опросы скрыты в релизной версии. Для тестирования их можно включить переключателем «Демо-режим» в настройках; после запуска они автоматически создают поток вымышленных зрителей.
- Несколько панелей получают общие результаты. Конфликт устаревшего черновика отклоняется; панель предлагает загрузить актуальную версию.
- Повреждённый файл данных не перезаписывается: запуск останавливается с сообщением. Сделайте копию файла перед восстановлением.
- OAuth и обработка событий Twitch проверяются автоматическими тестами с подменённым API. Перед публикацией установщик дополнительно проверяется на Windows вместе с OBS и настоящим Twitch-чатом.

## Разработка и проверка

```sh
npm run desktop
npm test
npm run check
npm run build
npm run clean
```

Панель написана на React 19 + TypeScript + Vite и использует компоненты shadcn/ui (Nova, Radix) и локально встроенный Geist. `npm run desktop` одновременно запускает Electron, локальный API и Vite: интерфейс обновляется через HMR, а изменения в `server/` и `desktop/` автоматически перезапускают Electron без ручной сборки. `npm run dev:desktop` оставлен как алиас, `npm run dev:panel` — для работы только в браузере. `npm run desktop:static` запускает заранее собранную production-панель.

`build` сначала создаёт production-панель в игнорируемой папке `public/panel-build`, затем собирает переносимую папку `dist` без пользовательских данных. `npm run clean` удаляет обе сборки и временные файлы упаковки. Запуск переносимой версии: `node server/index.mjs` или соответствующий стартовый файл. `pack:win` создаёт NSIS-установщик, `pack:mac` — локальную macOS-сборку для проверки оболочки. `PORT` меняет порт, `POLL_DATA_DIR` — папку состояния исходной версии; установленное приложение всегда использует системную папку пользователя.

Структура: `desktop/` — Electron-оболочка, безопасный preload-мост и контроллер обновлений, `server/polls.mjs` — правила голосования и шаблоны, `server/store.mjs` — последовательные атомарные записи, `server/twitch.mjs` — OAuth и чат, `server/app.mjs` — HTTP/SSE, `ui/panel/` — исходники shadcn-панели, `public/` — OBS-оверлеи, `tests/` — логика, восстановление, Twitch, обновления и HTTP/SSE.

Адаптер Twitch передаёт `vote` с идентификаторами пользователя, сообщения и канала; запоздавшие сообщения до начала опроса не учитываются. Страница оверлея не вызывает команды управления; она подписывается только на изменения состояния.
