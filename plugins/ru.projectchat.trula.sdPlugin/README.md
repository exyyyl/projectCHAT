# Trula Audio для Stream Dock — 0.1.0

Два действия: **«Звук на стриме»** управляет музыкой источника Trula OBS; **«Звук у стримера»** — музыкой в панели Trula. Нажатие выключает заказы и плейлист, повторное нажатие возвращает их отдельные прежние уровни. Громкость оповещений и озвучки не меняется. Выключение действует и на следующие треки до повторного нажатия.

## Установка в Stream Dock AJAZZ на Windows

1. Полностью закройте Stream Dock, в том числе в трее.
2. Распакуйте `Trula-Audio-0.1.0.zip`. Скопируйте папку `ru.projectchat.trula.sdPlugin` целиком в `%APPDATA%\HotSpot\StreamDock\plugins`. Если она уже существует, сохраните её копию перед заменой. Папка `node_modules` из ZIP обязательна.
3. Запустите Stream Dock. В категории **Trula Audio** перетащите два действия на кнопки.
4. Выберите любую из этих кнопок, вставьте ссылку док-панели Trula или токен и нажмите **«Подключить Trula»**. Подключение используется обеими кнопками.
5. В настройках звука самой Trula выберите вывод **«Оба»**. Плагин не меняет этот режим автоматически. Для отключённого выхода кнопка покажет «Выход выкл.».

Нужен Stream Dock со встроенным Node.js 20; версия из manifest — минимум `3.10.191.0421`. Разные сборки AJAZZ/Mirabox могут использовать другую папку плагинов. В таком случае используйте папку вашей сборки. Отдельно устанавливать Node.js на компьютер стримера не нужно. Плагин объявляет Windows и macOS; работа в настоящем Stream Dock на обеих системах требует ручной проверки.

## Настройка звука

- Источник Trula в OBS должен выводить музыку на стрим. Панель Trula должна быть открыта и воспроизводить музыку для стримера. Плагин управляет громкостью, но сам не является плеером.
- Для независимых выходов настройте захват так, чтобы музыка панели не попадала на стрим через захват рабочего стола. Иначе выключение источника не уберёт вторую копию музыки.
- Если стример слушает музыку через мониторинг того же источника OBS, кнопка панели не управляет этим мониторингом. Нужны отдельные пути звука, описанные выше.
- Значок и надпись отражают фактические настройки Trula. Изменения из самой Trula синхронизируются примерно за 5 секунд. При ошибке показывается «Нет связи», нажатие получает значок предупреждения.
- Если плагин ещё не запомнил громкость, а музыка уже выключена, включение установит 50%. Обычно запоминаются оба прежних уровня, включая разную громкость заказов и плейлиста.

## Токен и отключение

Токен вводится в скрытом поле и сохраняется в глобальных настройках Stream Dock. Это стандартное локальное хранилище приложения, **без дополнительного шифрования плагином**; оно может входить в резервные копии/экспорт профилей Stream Dock. В коде, ZIP и логах токена нет. Запросы идут только на `https://trula.io`, токен передаётся заголовком `token`.

Кнопка **«Отключить»** удаляет токен и запомненные уровни из настроек плагина. Она не включает музыку обратно и не отзывает токен на стороне Trula. Перед удалением плагина включите нужные выходы или выставьте громкость в Trula вручную.

## Сборка из исходников

Из корня репозитория:

```sh
npm ci --omit=dev --ignore-scripts --prefix plugins/ru.projectchat.trula.sdPlugin
node --test tests/trula-plugin.test.mjs
node scripts/package-trula-plugin.mjs
```

Сборщику нужны установленные зависимости корневого проекта (`sharp`) и Python 3 для ZIP. Архив появляется в `release/Trula-Audio-0.1.0.zip`; в нём уже есть зависимость `ws`. Cue для работы плагина не требуется.

## Проверка и границы

Контракт API получен из публичного кода панели Trula (`/cp/`, версия ассета `index-DupUm12Q.js`) и проверен запросами к сервису. Используется `GET/PATCH /api/v1/widget/panel/`, поля `panel/source.orderVolume`, `playlistVolume` и `panel.volumeSource`. Это внутренний API без обещания совместимости со стороны Trula.

Автотесты проверяют изоляцию выходов и оповещений, восстановление уровней, повторные нажатия, ошибки, недоступный выход, HTTP и протокол регистрации Stream Dock. Они не заменяют проверку звука в OBS и на физическом устройстве.

Основа протокола: [официальный SDK Stream Dock](https://github.com/MiraboxSpace/StreamDock-Plugin-SDK), [Node.js в manifest](https://sdk.key123.vip/en/guide/manifest.html), [события SDK](https://sdk.key123.vip/en/guide/events-sent.html).
