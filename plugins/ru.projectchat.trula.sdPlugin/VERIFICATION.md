# Проверка Trula Audio 0.1.0

- Реальный API Trula: отключение и восстановление музыки активного выхода контроллером; независимое отключение второго выхода; финальный GET полностью совпал с исходным снимком всех настроек аккаунта. Режим вывода не менялся.
- Автоматические тесты: два выхода и разные исходные уровни, оповещения, восстановление после перезапуска, быстрые повторные нажатия, отключённый выход, наследование громкости, ошибки записи, безопасный HTTP, manifest и регистрация/управление через локальный WebSocket Stream Dock. Дополнительно проверяется сохранение вводимой ссылки при обновлении статуса инспектора.
- Статический детектор интерфейса: замечаний нет. Окно просмотрено в браузере при ширине 320 и 480 px.

Независимый обзор интерфейса: **ship — pass**.

| Проверка | Вердикт |
|---|---|
| TYPE: incumbent system typography | Match |
| MATERIAL: flat dark operational surface | Match |
| Form spacing and primary action | Pass |
| Narrow-width wrapping and truncation | Pass |
| Labels, focus, live status and recovery copy | Pass |
| Independent output behavior | Supported by inspected runtime |

Визуально проверено начальное состояние. Подключённое состояние, загрузка и ошибки оценены по коду; управление проверено через имитацию хоста Stream Dock. На физическом Stream Dock и по реальному аудиосигналу OBS плагин ещё не проверен. Предназначен для первого ручного теста.
