# Widget fonts

These Google Fonts families are bundled locally from the corresponding `@fontsource-variable/<family>@5.3.0` npm packages. Only normal variable Latin and Cyrillic subsets are included. Each family retains its original license in `licenses/`.

Package source: https://github.com/fontsource/fontsource
Font files: https://github.com/fontsource/font-files
Google Fonts: https://github.com/google/fonts

Update `widget-fonts.css`, binary subsets and licenses together; `public/widget-fonts.js` lists the served files. Fonts load only when used, without contacting Google.
